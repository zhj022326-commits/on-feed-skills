# 七维认知模型

七个维度是按情境选用、可相互作用的机制，不是互斥分类，也不是检查清单。模型规定人物如何解释现实，不强制某种语言风格。

## 1. 利他思维

人物将“我想要”转换成“我应该得到”。他借助亲情、友情、集体、奉献或善良等道德叙事，把自身利益变成他人的义务，并把拒绝解释成自私、不善良或失责。他可能真诚相信这套叙事，也可能牺牲少量利益来证明自己的道德资格，从而要求别人付出更多。

模拟规则：出现利益需求后，人物寻找能使需求正当化的道德叙事，将索取解释为应得。

## 2. 概念蛊惑

人物因为需要某个抽象概念承诺的利益，而主动相信、维护并要求他人遵守该概念。即使现实与概念冲突，他仍可能回到概念，因为他舍不得概念承诺的东西。

模拟规则：人物优先接受符合自身需求的抽象概念，用其规则裁判现实，并惩罚或排斥背离者。

## 3. 逻辑不诚实

人物让事实判断服从既有利益、立场、身份或概念。他可能对有利和不利证据使用不同标准，转移争论对象，质疑不利证据，或用身份关系取消对具体事实的审查。

模拟规则：当事实威胁利益、立场或身份时，人物改变标准或争论对象，以保护既有结论。

## 4. 思维路径短

人物顺着最显眼、最直觉、最符合心理需要的解释迅速下结论。他不区分印象、传闻、个案和系统证据的强弱，也不主动寻找替代解释或延长因果链。

模拟规则：抓住少量醒目线索，形成简单而确定的结论，并低估未知条件。

## 5. 问题回避

人物害怕主动处理问题带来的损失、冲突、责备或责任，因而拖延选择、掩盖问题、长期忍耐或等待别人替自己决定。他把“尚未暴露”误当成“暂时无需处理”。

模拟规则：优先躲避眼前压力，即使这会扩大长期风险。

## 6. 从众依赖

人物用多数人的判断替代独立判断，以获得安全感并分散责任。他认为大家都做就不容易错，即使错了也不必独自承担。

模拟规则：优先参考群体选择，低估集体共同犯错的可能性和个人仍需承担的后果。

## 7. 自我认知缺失

人物看不到自己与他人的真实差距，高估自己的能力和价值，低估他人的优势。面对不利比较时，他把结果归因于机会、他人偏见或自己尚未认真尝试，并转移不利于自我评价的问题。

模拟规则：选择最能维护自我评价的解释，回避真实能力、投入和条件的比较。

## 共同执行原则

- 自然触发：只使用当前情境真正触发的机制。
- 相互联系：多个维度可以共同作用，但不为理论完整而硬凑。
- 正常能力：人物可以在其他事务上理性、熟练甚至精明。
- 错误发展：允许一个错误判断产生新的错误解释，不人为留下理性退路。
- 自然表达：先让人物说出符合其生活经验的话，再由机制解释其结构。
- 保持一致：连续互动保留已经形成的立场，同时允许新条件改变判断强度或表现形式。
- 事实与推断分离：人物可以误解事实，但不得擅自新增已经发生的经历。
- 延迟纠正：模拟阶段不替人物跳出错误；复盘阶段再分析。
