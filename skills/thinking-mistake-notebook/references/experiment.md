# 认知实验流程

认知实验是默认模式。先把输入整理成可研究、经用户确认的剧情，再模拟人物当下如何理解事件。不要未经选择连续虚构后续。

## 一、处理输入

### 用户给出关键词

根据人物、事件、领域或零散词语生成三个明显不同的剧情。每个剧情简要包含：

- 基本人物与处境；
- 现实利益或关系冲突；
- 触发判断的具体事件；
- 尚未解决的选择或矛盾。

区别应来自冲突结构，而不只是更换姓名或表面场景。请用户回复数字选择，也允许其自由修改。选择后整理成待确认剧情，不直接开始模拟。

### 用户给出不完整剧情

合理补充缺失的人物背景、利益压力和现实冲突，但不要把补充写成用户已经确认的事实。展示整理后的剧情，并提供：

1. 确认，开始模拟
2. 重新生成补充内容
3. 我自己修改

### 用户给出完整剧情

保留已知事实，只做必要整理，不为制造冲突擅自修改。展示整理后的剧情，并使用同一组确认选项。

### 用户选择随机生成

不要求关键词，直接生成三个领域或冲突结构不同、可继续研究的剧情。用户选择后，将剧情整理并请求确认。

## 二、剧情质量准入

在请求确认前检查：

- 是否存在有意义的利益、关系、证据或决策冲突；
- 是否有条件触发至少一种认知机制；
- 是否有可继续展开、施压或改变的研究空间。

判断依据是认知冲突的质量，不是事件大小或文字长度。若不合格，不进入正式模拟，使用：

> 当前情境的认知冲突比较弱，直接模拟可能没有太多值得分析的内容。建议先增加一些条件。

并提供：

1. 自动增强当前剧情
2. 提供三个扩展方向
3. 我重新描述

自动增强或扩展后仍需展示给用户确认。不得绕过质量准入。

## 三、确认边界

只有用户确认整理后的初始剧情，才能进入正式模拟。确认前不得先写人物的错误思维。确认后的自由输入若只是推进条件，可以直接继续；若它实质改写初始事实，则先明确更新后的事实再继续，避免状态混乱。

## 四、模拟当前节点

用简洁、具体且有内在逻辑的方式呈现人物此刻如何理解当前事件。重点是推理与自我解释，不是长篇表演式故事。

必须遵守：

- 只处理当前主要节点，不擅自推进时间线；
- 不安排用户尚未选择的后续事件；
- 让相关认知缺陷自然影响判断，不硬凑七维；
- 不因错误显得明显就突然让人物作出理性决定；
- 保留人物正常经验、技能和现实利益计算；
- 若需补足人物内心想法，标明这是人物的主观理解，而非新增客观事实。

## 五、每轮推进

每次正式模拟后必须提供数字选项。通常给三个动态推进方向，再给固定复盘选项：

**选择下一步：**

1. 根据当前剧情生成的压力测试 A
2. 根据当前剧情生成的压力测试 B
3. 根据当前剧情生成的压力测试 C
4. 复盘

前三个选项要测试不同机制，例如新证据、利益损失、身份威胁、群体意见变化、关键条件改变或关系冲突升级；不要机械套用这些类别，也不要只是改写同一事件。每次只推进一个主要节点。

处理选择时：

- 新证据：保留人物与情境，观察人物如何吸收、否认或重解释证据。
- 条件变化：只修改用户指定的条件，再模拟这一变化的影响。
- 新增冲突：只引入所选的利益或关系变化。
- 复盘：结束错误认知模拟，按 `review.md` 分析已经发生的内容。
- 自由输入：识别用户真正想施加的条件；若不是复盘，就继续实验并在末尾再次提供动态选项和复盘。

不要把推进写成已经完成的一串故事。每轮都停在新条件触发的当下，让用户决定下一步。
